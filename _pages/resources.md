## Software

- [VESTA](https://jp-minerals.org/vesta/en/) — 3D visualization program for structural models, by JP Minerals
- [Dysnomia](https://jp-minerals.org/dysnomia/en/) — calculates electron and nuclear densities from observed structure factors by MEM
- [PowderPlot](https://jp-minerals.org/powderplot/en/) — Java program for plotting powder patterns output by RIETAN-FP (\*.itx / \*.pat)
- [McMaille Indexing Software](http://www.cristal.org/McMaille/)
- [Gnuplot](http://www.gnuplot.info/) — portable command-line driven graphing utility for Linux, Windows and macOS
